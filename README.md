# Quizzy

Live quiz in Kahoot-stijl: host + spelers via WebSockets.

## Thema

De app gebruikt een donkere skyline-video als achtergrond met warme amber/gouden accenten. De QR-code, geluidseffecten en optionele gospel-geïnspireerde instrumentale achtergrondmuziek zijn onderdeel van de enhanced UI.

## Starten

```bash
npm start
```

Docker start automatisch `enhanced-server.js`.
